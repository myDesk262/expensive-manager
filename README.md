# ExpensiveManager

A full-stack expense management system featuring user authentication (JWT), expense and category management, and secure RESTful APIs.

---

## Features

- User registration & login (JWT-based authentication)
- Expense CRUD (Create, Read, Update, Delete)
- Category CRUD (Create, Read, Update, Delete)
- Secure endpoints with Spring Security
- Unit and integration tests
- Manual/Postman API testing samples
- Modular, extensible Spring Boot backend

---
